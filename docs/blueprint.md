# **App Name**: Volt3D Showcase

## Core Features:

- Interactive Portfolio Display: Showcase a range of 3D and digital environment projects with detailed descriptions and categories.
- Dynamic Skill Visualization: Visually represent proficiency in various software tools and skills using progress bars and icon integrations.
- Contact Form Submission: Enable users to send messages directly through a contact form with validation and submission handling.
- Mobile-Responsive Navigation: Implement a responsive navigation menu that adapts to different screen sizes, ensuring seamless user experience on both desktop and mobile devices.

## Style Guidelines:

- Primary color: Cyan (#00BCD4) to convey innovation and a tech-forward feel.
- Background color: Dark slate gray (#37474F) to create a sophisticated backdrop and highlight the portfolio pieces.
- Accent color: Blue (#2962FF) to complement the cyan and provide visual contrast.
- Body and headline font: 'Space Grotesk' (sans-serif) for a modern and technical aesthetic. 'Inter' (sans-serif) for longer text.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use minimalist, geometric icons from Lucide React to represent skills and categories.
- Subtle fade-in effects and hover transitions to enhance user engagement.
